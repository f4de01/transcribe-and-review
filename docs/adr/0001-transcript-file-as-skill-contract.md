# 以逐字稿文件格式作为两个 skill 的串联契约

转写 skill（transcribe）和审查 skill（review）必须能独立安装、独立使用，但用户只有视频时又要能一条链走完。我们不做第三个编排 skill，也不做单 skill 双模式，而是把逐字稿文件本身当作接口：`[HH:MM:SS.mmm --> HH:MM:SS.mmm] 文字` 的 Markdown，文件头带格式版本标记。审查 skill 据此校验输入；输入是视频时，它在标准 skill 目录里寻找转写 skill 并先执行转写。编排 skill 意味着三份安装和一份额外维护；单 skill 违背独立安装的要求；文件契约只要求双方遵守同一格式，任一方缺席时另一方仍可单独工作。

## Consequences

- 逐字稿格式一旦改动就是破坏性变更，必须同时升级版本标记和两个 skill。
- 用户已有的、由旧版转写 skill 产出的逐字稿可以直接送审。
